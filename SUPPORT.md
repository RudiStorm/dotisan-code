# Support

Use GitHub Issues for reproducible bugs and feature proposals. Include the Dotisan version, .NET SDK version, operating system, package manager, profile, database provider, exact command, and a minimal reproduction.

Security vulnerabilities must not be reported in public issues; follow [SECURITY.md](SECURITY.md).

Dotisan is an open-source scaffolding tool. Support is best-effort and community-driven; application-specific generated code, deployment infrastructure, and third-party provider behavior remain the adopter's responsibility.
