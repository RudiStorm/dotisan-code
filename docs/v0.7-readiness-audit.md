# v0.7.0 Readiness Audit

Audit date: 2026-09-02

The pre-v0.7 foundation requirements from the Spec Kit are implemented. The active checklist is tracked in `docs/todo-v070-spec-kit.md`; all seven items are complete.

Completed areas:

- Tenant claim resolution, development header fallback, required tenant writes, and generated CRUD tenant predicates.
- Aspire Dashboard development Compose support and `dotisan dev --observability`.
- OpenTelemetry ASP.NET Core, HTTP, EF Core, metrics, and logging instrumentation with provider-neutral OTLP configuration.
- Generated Vue Test Utils, Vitest/jsdom, Playwright, Tailwind/PostCSS, and shadcn-vue-compatible editable UI conventions.
- Explicit `dotisan add:integration` and safe `dotisan remove:integration` recipes.
- EF Core migration rollback guidance using `dotnet ef database update <MigrationName>`.
- Authentication security foundation: email confirmation, password reset, TOTP MFA, recovery codes, sessions/devices, provider-neutral external login, and console/Mailpit/SMTP mail selection.
